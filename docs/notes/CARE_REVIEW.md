Scope: app/care.py, data/care_actives.json, static/family.js, static/care.js, the Care hooks in static/app.js and scripts/build_preview.py. I tested in a mock server (`MOCK=1`, port 8097) with Playwright/Chromium. ## What passed

- **Tests and lint:** pytest 96/96; ruff clean.
- **Plate regression:** Gill sample → adapt all → ask ("Dad hates cauliflower") → Plan my week (intake) → family book → Copy as text → close → reload. The visible text is identical to the pre-Care build except for the intended renames: "cookbook" → "family book" and the eyebrow "Heritage Plate" → "Heritage". The hash is now `#plate`. Close returns focus to `#weekTitle` as before. No console errors in either build.
- **Umbrella home:** both doors route correctly (`#plate` focuses `heroTitle`, `#care` focuses `careTitle`). Returning users land on their last side. Switch targets are 138×46 px.
- **Remedy check:** empty text gives the spec message. `<img onerror>` and `<script>` in typed text and in a quick-added name (`Riya<b>`) are escaped everywhere: result, "for" line, chips, family book, copied text. All 4 chips give the expected verdicts. Double submit (click, click, Ctrl+Enter) sends exactly 1 request. Focus moves to the remedy heading. Save → "See your family book" gets focus. The book shows the remedy, and Back returns to Care.
- **Care plan:** 0 members, a member with no concerns, a 7th concern (blocked with a toast), and 6 members (Add hidden) all behave correctly. Remove and Undo work. Pregnant member: adapalene and retinol become "Not during pregnancy" notes, and benzoyl peroxide carries the "ask a doctor" note. Red-flag-only member: doctor callout and an empty routine. Under 18: minoxidil and finasteride become doctor notes. Prescription items appear only as "Ask your doctor about…".
- **Label check:** example label, empty input, HTML in the label, and the 3000-character maxlength all work. Pregnancy warning for retinyl palmitate. Fatty alcohols are correctly not flagged.
- **Storage:** v1-only data migrates to v2 (mode plate, Mum as member 1, v1 left in place). Corrupt or wrong-version v2 falls back cleanly. A hostile v2 (XSS strings, `javascript:` URLs, bad types, duplicate ids) renders with 0 injected elements and 0 `javascript:` links.
- **Robustness:** request size limits hold (text 400, details 300, at most 6 members and 6 concerns). Unknown language returns 422. The plan costs 2 rate-limit units. The label endpoint is code-only. Huge or NaN model text is truncated, and no NaN reaches the JSON.
- **Layout and errors:** 320/375/1280 px in light and dark: no horizontal scroll on home, remedy, plan form, plan output, label or book. Dark tokens apply. No console errors. Print emulation renders the book.
- **Model names:** only "Built with NVIDIA Nemotron on Nebius" is visible on the Care screens. `/api/health` and Plate's existing "Under the hood" trace still name tiers, as before.
- **Preview:** `build_preview.py --standalone` builds (1.2 MB). Opened from file://, it runs the 4 chips, the sample plan, the example label and the Plate sample → week → book with no network requests and no errors.
